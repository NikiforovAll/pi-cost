pi-cost

Cost dashboard for the pi coding agent. Reads JSONL session files from the sessions dir under the pi agent dir (PI_CODING_AGENT_DIR, default ~/.pi/agent), or from the custom session dir that pi is set to use.

Costs come from two sources:

actual — pi recorded the cost in the JSONL.
est — computed from token counts and LiteLLM pricing (refreshed every 6h).
